# YUマーケット

山口大学の学内で、不要になった物を**無償でゆずりあう**ためのサイトです。
お金のやり取りは一切なく、価格・決済の機能はありません。

ワイヤーフレーム10画面をそのまま動かせるようにした、フロントエンドのみの実装です。

## 画面

| 画面 | ハッシュ | 内容 |
| --- | --- | --- |
| ログイン | `#/login` | メールアドレス・パスワード、新規登録への導線 |
| 新規登録 | `#/signup` | メールアドレス・パスワード（8文字以上）・確認入力 |
| ホーム | `#/home` | 検索窓、カテゴリー絞り込み、あなたへのおすすめ、新着商品 |
| 検索 | `#/search` | カテゴリー／色／受取場所／取引可能期間／キャンパスで絞り込み、一覧表示 |
| 検索結果 | `#/results` | キーワード検索の結果をリスト表示。条件はチップで表示し「×」で解除 |
| 「欲しいです」検索 | `#/wants` | ゆずってほしい物の募集を、同じ条件で絞り込んで検索 |
| 「欲しいです」検索結果 | `#/wants-results` | 募集をリスト表示（名前・カテゴリー・色・受け渡し可能期間）。条件はチップで解除 |
| 「欲しいです」の詳細 | `#/want/:id` | 募集内容と投稿者。「ゆずります」で出品フォームに内容を引き継ぐ |
| 「欲しいです」の投稿 | `#/want-new` | 欲しい物・カテゴリー・色・受取場所・期間・キャンパスを指定して募集 |
| 欲しいものリスト | `#/favorites` | 商品詳細の「欲しい」で保存した商品の一覧 |
| 投稿した「欲しいです」 | `#/my-wants` | 自分が出した募集の確認・取り消し |
| 商品詳細 | `#/item/:id` | 写真・商品説明・カテゴリー・色・状態・受け渡し可能期間・場所・キャンパス |
| 申込確認 | `#/apply/:id` | 受取可能日・受取希望場所・メッセージ・利用規約への同意 |
| 出品情報の入力 | `#/sell` | 写真の追加、商品名、各項目の選択、商品の説明 |
| 申込中の商品 | `#/applications` | 申込日と状態。受け渡し日時の確定・申し込みの取り消し |
| 取引中 | `#/deals` | 受取日・受取場所の確認と受け渡し完了 |
| 取引履歴 | `#/history` | 完了した取引の一覧 |
| 出品中の商品 | `#/listings` | 自分の出品の確認・取り消し |
| プロフィール | `#/mypage` | 名前・学部・キャンパスの編集、各画面へのメニュー |
| 設定 | `#/settings` | 保存データの初期化、ログアウト |

申し込みは「申込中 → 取引中 → 取引完了」と進み、それぞれ申込中の商品・取引中・取引履歴の画面に表示されます。

「欲しいです」には2つの使い方があります。

- **募集**：欲しい物を投稿すると、検索タブの「「欲しいです」を探す」から誰でも探せます。
  ゆずれる人は詳細画面の「ゆずります」を押すと、募集内容が入った状態の出品フォームが開きます。
- **欲しいものリスト**：商品詳細の「欲しいものリストに追加」で気になる出品を保存し、
  マイページの「欲しいものリスト」からまとめて見られます。

## 動かし方

Node.js があれば、付属の簡易サーバーで開けます。

```bash
node server.js
```

- このPC: <http://localhost:3000>
- スマホ: 起動時に表示される `http://<PCのIPアドレス>:3000`（同じWi-Fiに接続していること）

`docs/index.html` をブラウザで直接開いても動作します。
GitHub Pages を `docs/` フォルダで公開する設定にすれば、そのまま公開できます。

## 構成

```
docs/
  index.html   全画面のマークアップ
  style.css    スタイル
  app.js       画面遷移・検索・出品・申込などの処理
server.js      動作確認用の簡易HTTPサーバー
```

## 制限事項

サーバーとデータベースはまだありません。アカウント・プロフィール・出品・申込は、
すべて利用している端末のブラウザ（localStorage）にのみ保存されます。
そのため次の点に注意してください。

- 別の端末やブラウザからは、登録した内容は見えません。
- 商品の初期データ12件はサンプルです。
- パスワードを端末に保存しているため、このままの実装で公開しないでください。
  公開時は認証とデータ保存をサーバー側に置き換える必要があります。
