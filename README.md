# YUマーケット

山口大学の学内で、不要になった物を**無償でゆずりあう**ためのサイトです。
お金のやり取りは一切なく、価格・決済の機能はありません。

公開先: <https://nihiro0714.github.io/akatuki/>

画面はバニラの HTML/CSS/JS（ハッシュルーター）で作り、ログインとデータ保存に Supabase を使っています。

## 画面

| 画面 | ハッシュ | 内容 |
| --- | --- | --- |
| ログイン | `#/login` | メールアドレス・パスワード、新規登録への導線 |
| 新規登録 | `#/signup` | 山口大学のメールアドレス・パスワード（8文字以上）・確認入力。確認メールのリンクを開いて登録完了 |
| ホーム | `#/home` | 検索窓、カテゴリー絞り込み、おすすめ（新着の上位）、新着商品 |
| 検索 | `#/search` | カテゴリー／色／受取場所／取引可能期間／キャンパスで絞り込み、一覧表示 |
| 検索結果 | `#/results` | キーワード検索の結果をリスト表示。条件はチップで表示し「×」で解除 |
| 商品詳細 | `#/item/:id` | 写真・商品説明・各項目・出品者。自分の出品や受付終了の出品には申し込めない |
| 申込確認 | `#/apply/:id` | 受取可能日・受取希望場所・メッセージ・利用規約への同意 |
| 出品情報の入力 | `#/sell` | 写真の追加（長辺1024pxに縮小、iPhone の HEIC にも対応）、商品名、各項目、商品の説明 |
| 出品中の商品 | `#/listings` | 自分の出品と状態（出品中／取引中／譲渡済み／取消済み）。受付中の出品の取り消し |
| 届いた申込 | `#/received` | 自分の出品への申込を出品ごとに表示。承認・断る、取引中の相手の連絡先・受け渡し完了・取り消し |
| 申込中の商品 | `#/applications` | 自分の申込。申し込みの取り消し |
| 取引中 | `#/deals` | 承認された自分の申込。受取日・受取場所・出品者の連絡先 |
| 取引履歴 | `#/history` | 完了した取引（ゆずった・ゆずってもらった両方） |
| プロフィール | `#/mypage` | 名前・学部・キャンパス・プロフィール画像の編集、各画面へのメニュー |
| 設定 | `#/settings` | 利用規約、ログアウト（この端末のみ） |
| 利用規約 | `#/terms` | 運営・無償譲渡・トラブル・メールアドレスの扱い。ログイン前でも読める |

## 取引の流れ

1. 出品者が写真付きで出品する
2. ほかの学生が商品詳細から申し込む（申込中）
3. 出品者が「届いた申込」で承認する（取引中）
   - 同じ出品へのほかの申込は自動で取消になり、出品は検索に出なくなる
   - 出品者と申込者の双方に、相手のメールアドレスが表示される
4. 受け渡しが済んだら、出品者が「受け渡し完了」を押す（取引完了）
   - 両者の取引履歴に載る

承認・受け渡し完了・取消は、データベースの関数（RPC）でだけ行えます。画面から申込の状態を直接書き換えることはできません。

## 動かし方

### Supabase の準備（最初に1回）

1. Supabase でプロジェクトを作る
2. SQL Editor で `supabase/schema.sql` を実行する
3. Authentication → URL Configuration で次を設定する
   - Site URL: `https://nihiro0714.github.io/akatuki/`
   - Redirect URLs: `https://nihiro0714.github.io/akatuki/**` と `http://localhost:3000/**`
4. Project Settings の Project URL と anon（Publishable）key を `docs/config.js` に書く

### ローカルで開く

```bash
node server.js
```

- このPC: <http://localhost:3000>
- スマホ: 起動時に表示される `http://<PCのIPアドレス>:3000`（同じWi-Fiに接続していること）

ローカルから新規登録した場合、確認メールのリンクは localhost に戻るので、PC で開いてください。

### 公開

`main` ブランチに push すると、GitHub Pages が `docs/` を公開します。

## 構成

```
docs/
  index.html   全画面のマークアップ
  style.css    スタイル
  app.js       画面遷移・認証・検索・出品・申込などの処理
  config.js    Supabase の接続先（anon key は公開前提の鍵）
supabase/
  schema.sql   テーブル・RLS・RPC・Storage の定義（SQL Editor で実行する）
server.js      動作確認用の簡易HTTPサーバー
```

外部ライブラリは CDN から読み込みます（supabase-js、HEIC の写真を読むときだけ heic2any）。

## 制限事項

- 登録できるのは `@yamaguchi-u.ac.jp` のメールアドレスだけです。
- **通知はありません。** 申込・承認・完了があっても、メールやプッシュ通知は届きません。相手の画面は再読み込みしたときに更新されます。
- 取引が成立したあとの連絡は、表示されたメールアドレスで当事者同士が行います。
- 「欲しいです」（募集）と欲しいものリストは**未公開**です。コードは残してあり、`docs/app.js` の `ENABLE_WANTS` で切り替えます。有効にしても、データはまだ端末の localStorage にしか保存されません。
- Supabase の無料プランは、1週間アクセスが無いとプロジェクトが一時停止します。
- Supabase 標準のメール送信は時間あたりの上限が小さく、確認メールが遅れることがあります。
